# ci-cd-pipeline-githubactions_terraform
A professional CI/CD pipeline using GitHub Actions and Terraform to deploy on AWS EC2.

## 🔧 Tech Stack
- GitHub Actions (CI/CD)
- Docker (Containerization)
- Terraform (Infrastructure as Code)
- AWS EC2 (Deployment)
- Slack (Alerts)

## 📁 Structure
- `app/` – Source code
- `terraform/` – Infrastructure definitions
- `.github/workflows/` – GitHub Actions CI/CD configs
